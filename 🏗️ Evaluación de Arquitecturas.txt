❌ CONTRAS:
Complejidad de Build: Frontend y backend en el mismo repo causan conflictos
Netlify Functions: Limitaciones de timeout (10s), cold starts, debugging complejo
Variables de Entorno: Conflictos entre prefijos VITE_ y variables de backend

CSP Issues: URLs relativas causan problemas de seguridad persistentes
✅ PROS:
Un solo repositorio para mantener
Compartir tipos TypeScript entre frontend/backend
Deploy unificado
